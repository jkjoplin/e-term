# e-term

Turn a jailbroken Kindle into an e-paper terminal for the computers on your desk.

The Kindle runs a terminal and SSHes into a tmux session on one of your computers. Claude Code, editors and shells keep running on the computer; the Kindle is the screen, lit by its warm front light. Eink Focus, a companion app for macOS and Android, finds that session and types into it from your real keyboard or your phone, so you don't type on the Kindle's on-screen keyboard.

```
 Kindle (jailbroken)                         Your computers (macOS, or any host with sshd + tmux)
┌───────────────────────────┐   SSH over     ┌──────────────────────────────────────┐
│ kterm                     │   Tailscale    │ sshd → tmux session "eink"           │
│  └ eterm/connect.sh       ├───or LAN──────▶│         └ claude, vim, a shell, ...  │
│     └ dbclient (Dropbear) │                └──────────────────────────────────────┘
└───────────────────────────┘                         ▲  tmux send-keys
        you read here                                 │
                                    Eink Focus (Mac menu-bar app or Android phone)
                                    finds the Kindle's tmux client and types into it
```

## What's here

| Part | What it does | Guide |
| --- | --- | --- |
| [`kindle/`](kindle/) | Files that go on the Kindle: the terminal wrapper, a host menu that SSHes into your computers, launcher books, Tailscale, an optional sleep screen, plus Mac-side helper scripts for the jailbreak. | [docs/kindle.md](docs/kindle.md) |
| [`mac/`](mac/) | **Eink Focus for macOS**, a menu-bar app. One shortcut sends your keyboard to the Kindle's tmux session, with a desk card showing what you're typing. Dictation, session and computer switching, copy and paste. | [mac/README.md](mac/README.md) |

| [`config/`](config/) | Templates for the apps' settings. Your filled-in copies are gitignored. | [docs/configuration.md](docs/configuration.md) |

## Setup, in order

1. **Prepare the Kindle.** Identify the model and firmware, block updates, jailbreak it, install KOReader (for its SSH client) and kterm. → [docs/kindle.md](docs/kindle.md)
2. **Prepare each computer.** Turn on SSH, authorize the Kindle's key, install tmux and the `kterm-256color` terminfo entry. → [docs/computers.md](docs/computers.md)
3. **Connect them.** Fill in the Kindle's host list, copy the `eterm` files across, and optionally put the Kindle on Tailscale so it reaches computers off your LAN. → [docs/kindle.md](docs/kindle.md#5-the-host-menu-eterm)
4. **Type from a real keyboard.** Install Eink Focus on a Mac ([mac/README.md](mac/README.md)) and/or an Android phone ([android/README.md](android/README.md)).

[docs/how-it-works.md](docs/how-it-works.md) explains how the apps find the Kindle, deliver keys, and move it between computers. [docs/notes.md](docs/notes.md) collects the research behind the choices: which jailbreak, hard-float packages, refresh rates, and what TUIs do to an e-ink panel.

## Your details stay local

Nothing personal is in this repository. Each file that holds addresses, usernames, device names or keys is gitignored, and a template sits next to it:

| Your file (gitignored) | Template | Holds |
| --- | --- | --- |
| `kindle/eterm/hosts` | `kindle/eterm/hosts.example` | The computers the Kindle can log into |
| `config/eink-focus.json` | `config/eink-focus.example.json` | Eink Focus for Mac settings |
| `config/eink-focus-android.json` | `config/eink-focus-android.example.json` | The phone's host list, generated by `android/provision.sh` |
| `kindle/tailscale/hostname` | (one word) | The Kindle's name on your tailnet |
| `ssh/` | (none) | The Kindle's SSH key pair |
| `payloads/` | (none) | Third-party downloads, listed in [docs/kindle.md](docs/kindle.md#downloads) |

## Status

This is a personal project that works daily on a Kindle Paperwhite 5 (firmware 5.16.7) and a Kindle Scribe, with macOS computers and a Pixel phone. Other Kindles should work once jailbroken, because the Kindle side is plain shell, but the jailbreak itself depends on the exact model and firmware. Check the [Kindle Modding](https://kindlemodding.org/) wizard for yours.

Jailbreaking can brick a device and voids its warranty. Read every step of [docs/kindle.md](docs/kindle.md) before you start, and keep a recovery path (USB networking) working before you experiment.
